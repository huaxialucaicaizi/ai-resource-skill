# 课程避坑清单（只讲判断标准）

> 本页只提供「怎么判断一门付费 AI 课值不值得买」的标准。不点名、不批评任何具体机构、课程或个人。

适合：准备掏钱学 AI 之前先过一遍；或对比「免费官方课 vs 付费课」时使用。

---

## 先问自己三个问题

1. **我现在最想解决的一件事是什么？**（例如：用 AI 做 PPT、看懂行业新闻、系统入门）  
   目标越具体，越不容易被「包教会 / 全能班」带走。
2. **这件事有没有免费或官方材料可以先试？**  
   本仓库「系统学习」和「场景教程」里有不少可公开访问的选项；先试再决定是否付费。
3. **我能不能接受「课程内容会过时」？**  
   模型与工具更新很快。一门课若从不说明更新策略，风险更高。

---

## 红旗信号（出现越多，越要谨慎）

- **承诺过度**：保证「包就业 / 包月入过万 / 不学会退全款」却说不清考核标准与例外条款。
- **神秘与制造焦虑**：强调「内部资料 / 即将涨价 / 仅限今天」却不愿给出可核验的大纲样例。
- **只展示结果不展示过程**：全是精美成品，没有可复现的步骤、工具名单与作业要求。
- **工具绑定含糊**：不写清要用哪些产品、是否另付 API / 会员费、国内能不能打开。
- **师资与更新不可核验**：讲师背景、是否亲自答疑、课程多久更新一次，全部无法查证。
- **与公开免费资源高度重叠**：大纲几乎是公开文档/官方课的重新打包，却标高价且不说明差异。
- **强迫先付大额再看内容**：付费前看不到完整目录、试听范围或退款规则。

---

## 付钱前建议问清的问题

向销售或页面确认（能白纸黑字更好）：

1. **完整大纲**：每周主题、作业形式、是否需要编程基础。  
2. **更新承诺**：模型大改版后是否免费更新？更新频率如何？  
3. **费用全貌**：学费之外是否还要买软件、算力、社群续费？  
4. **退款与服务边界**：答疑时长、是否录播、过期后能否回看。  
5. **国内访问**：依赖的平台链接，在中国大陆网络下是否可用；不可用时有无替代方案。  
6. **成果定义**：结业标准是什么；「作品集」是否可公开验证，而非仅截图。  
7. **与免费路径的差异**：为什么不能先学本仓库列出的免费/官方课，再补你们多出来的部分？

若对方回避以上问题，建议先缓一缓。

## 免费 / 低成本替代怎么找

1. 打开本仓库 [系统学习](./learning.md)：优先看标注为公开仓库、官方学院、或证书可选付费的课程。  
2. 打开 [场景教程](./tutorials.md)：按「做 PPT / 写代码 / 做视频 / 数据分析」找可公开观看的短教程。  
3. 注意每条源的标签：  
   - **国内能否直接访问**（含「未知（未实测）」）  
   - **免费/付费**（证书费 ≠ 一定要付才能旁听，以该条原文为准）  
   - **适合谁**  
4. 用 Skill 生成专属清单时，助手必须提醒你访问限制与付费点，且不得编造名单外的课程。

## 怎么判断「可能值得」

没有万能公式。相对更稳妥的信号包括：

- 大纲具体、可核对，和你的单一目标对齐；  
- 明确写出先修要求（会不会写代码、要不要科学上网）；  
- 允许试听或先完成一小节再付款；  
- 费用结构清楚，更新与退款规则写在可保存的页面上；  
- 你已经用免费材料验证过「自己愿意持续学」，而不是被情绪推着下单。

## 本清单不做什么

- 不点评、不排序、不点名任何培训机构或网红课。  
- 不把「贵」或「便宜」单独当成好坏标准。  
- 不替代你自己的试学与合同阅读。
